# Herrería

## Uso

1. Usa la **Forja** para producir lingotes. Debes llevar equipados los Guantes
   de Fundidor.
2. Usa el **Yunque de herrero** para fabricar el producto final. Debes llevar
   equipado el Martillo ligero de herrero.
3. Deposita el molde y cualquier suministro adicional indicado por la receta.

Los moldes aparecen marcados con `*`: sobreviven a una tirada fallida y se
consumen al fabricar la pieza con éxito. Las recetas de armas marcadas con
`[elige]` abren una selección adicional; primero eliges el metal y después el
tipo de arma.

## Recetas

Las marcas de las tablas se explican en
[Cómo leer una receta](../../README.md#cómo-leer-una-receta).

## Variantes de armas

Las recetas de armas del Yunque permiten elegir entre estos productos:

Espada larga, Daga, Daga de asesino, Daga de hechicería, Espada corta, Espada
bastarda, Espadon, Espada de doble hoja, Espada maug, Cimitarra, Cimitarra
doble, Alfanje, Katana, Estoque, Espadon enorme, Hacha de batalla, Gran hacha,
Hacha de mano, Hacha de guerra enana, Hacha doble, Hacha arrojadiza, Hacha
enorme, Martillo de guerra, Martillo ligero, Maza, Maza pesada, Maza terrible,
Maza de armas, Mazo, Mazo enorme, Mangual ligero, Mangual pesado, Alabarda,
Lanza corta, Lanza larga, Lanza de guerra, Guadana, Tridente, Tridente ligero,
Pico pesado, Pico ligero, Hoz, Kama, Kukri, Katar, Sai, Rueda de fuego y
viento, Shuriken, Dardo y Látigo.
