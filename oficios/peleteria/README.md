# Peletería

## Uso

1. Usa la **Tina de curtido** para obtener cuero. Es una estación de proceso y
   no requiere herramienta.
2. Usa la **Mesa de peletero** para fabricar el producto final. Equipa una
   Aguja o Aguja grande y lleva en el inventario el Kit de herramientas para
   trabajar el cuero.
3. Deposita la plantilla y los demás componentes que indique la receta.

Las plantillas aparecen marcadas con `*`: sobreviven a una tirada fallida y se
consumen al fabricar la pieza con éxito.

## Recetas

Las marcas de las tablas se explican en
[Cómo leer una receta](../../README.md#cómo-leer-una-receta).
