# Alquimia

## Uso

1. Usa el **Caldero de hierbas** para preparar los ingredientes base. Requiere
   llevar equipados los Guantes de Cocinero.
2. Lleva esos preparados a la **Mesa de alquimia**. Requiere llevar equipados
   los Guantes de Alquimista.
3. Deposita exactamente los componentes indicados y confirma el intento.

Cuando una receta incluye una botella marcada con `*`, la botella se conserva
si la tirada falla y se consume si acierta. La alquimia tiene progreso propio,
pero no ocupa una de las plazas limitadas de oficio.

## Recetas

Las marcas de las tablas se explican en
[Cómo leer una receta](../../README.md#cómo-leer-una-receta).
