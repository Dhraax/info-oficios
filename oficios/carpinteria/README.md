# Carpintería

## Uso

1. Usa la **Tabla de serrería** para convertir leños en tablones. Debes llevar
   en el inventario el Kit de herramientas del serrador y la Sierra del
   serrador.
2. Usa el **Banco de carpintero** para fabricar el producto final. Debes llevar
   en el inventario el Kit de herramientas del carpintero.
3. Comprueba la cantidad de salida: las recetas de munición entregan una pila,
   indicada con `×-` en su nombre.

Las recetas marcadas con `[elige]` no fijan un único resultado. Después de
escoger la receta, el menú pide seleccionar el tipo de arma; la madera elegida
determina las propiedades del producto.

## Recetas

Las marcas de las tablas se explican en
[Cómo leer una receta](../../README.md#cómo-leer-una-receta).
